## Viewing Documentation

### Option 1 — Directly on GitHub (RECOMMENDED)

1. Open the `docs/` folder
2. Navigate to the relevant protocol category
3. Open the desired `.md` file

### Option 2 — Local Documentation Site

```bash
pip install mkdocs
mkdocs serve
```

Then open:

```
http://127.0.0.1:8000/
```
